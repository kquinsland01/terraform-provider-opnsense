# opnsense_kea_dhcpv4_subnet (Resource)

Manages a Kea DHCPv4 subnet through the stable OPNsense API. Set `auto_collect = false` when explicitly managing router, DNS, or NTP values; collections are preserved losslessly on import and refresh, and explicit empty values clear their remote options. `pools` remains a newline-compatible string. The resource may be safely configured while the Kea DHCPv4 service is disabled. Deprecated generic `opnsense_kea_peer`, `opnsense_kea_reservation`, and `opnsense_kea_subnet` aliases are intentionally not exposed.

## Example Usage

```terraform
resource "opnsense_kea_dhcpv4_subnet" "lan" {
  subnet        = "192.0.2.0/24"
  pools         = "192.0.2.100-192.0.2.199"
  auto_collect  = false
  dns_servers   = ["192.0.2.53", "192.0.2.54"]
  domain_name   = "example.test"
  domain_search = ["example.test", "services.example.test"]
  routers       = ["192.0.2.1"]
  static_routes = [{ destination = "198.51.100.1", router = "192.0.2.1" }]
  ntp_servers   = ["192.0.2.20"]
  time_servers  = ["192.0.2.21"]
  next_server   = "192.0.2.22"
  tftp_server   = "tftp.example.test"
  tftp_bootfile = "bootx64.efi"
  description   = "Managed DHCPv4 subnet"
}
```

## Schema

### Required

- `subnet` (String) Subnet in CIDR notation (e.g. `192.168.40.0/24`).

### Optional

- `allocator` (String) Lease allocator strategy (empty = default, `iterative`, `random`, or `flq`).
- `auto_collect` (Boolean) Automatically collect router, DNS, and NTP option data from OPNsense. Set false to manage those values explicitly.
- `description` (String) Description of the subnet.
- `dns_servers` (Set of String) IPv4 DNS servers offered to clients.
- `domain_name` (String) Domain name offered to clients.
- `domain_search` (Set of String) Domain-search suffixes offered to clients.
- `match_client_id` (Boolean) Match clients by client-id in addition to hardware address. Defaults to `true`.
- `next_server` (String) IPv4 next-server address used for network boot.
- `ntp_servers` (Set of String) IPv4 NTP servers offered to clients.
- `ping_check` (Boolean) Ping the address before handing out a lease. Defaults to `false`.
- `pools` (String) Address pools for the subnet (newline-separated ranges).
- `routers` (Set of String) IPv4 default routers offered to clients.
- `static_routes` (Attributes Set) IPv4 destination/router pairs encoded by OPNsense as one flat comma-separated sequence. (see [below for nested schema](#nestedatt--static_routes))
- `tftp_bootfile` (String) Network boot filename offered to clients.
- `tftp_server` (String) TFTP server name or address offered to clients.
- `time_servers` (Set of String) IPv4 RFC 868 time servers offered to clients.

### Read-Only

- `id` (String) UUID of the subnet.
