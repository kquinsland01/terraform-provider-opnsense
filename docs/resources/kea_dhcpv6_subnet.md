# opnsense_kea_dhcpv6_subnet (Resource)

Manages a Kea DHCPv6 subnet. DNS and domain-search collections preserve API truth on import and refresh. The resource may be configured while the Kea DHCPv6 service is disabled. Deprecated generic `opnsense_kea_peer`, `opnsense_kea_reservation`, and `opnsense_kea_subnet` aliases are intentionally not exposed.

## Example Usage

```terraform
resource "opnsense_kea_dhcpv6_subnet" "lan" {
  subnet        = "2001:db8:31::/48"
  interface     = "lan"
  dns_servers   = ["2001:db8:31::53", "2001:db8:31::54"]
  domain_search = ["example.test", "services.example.test"]
  description   = "Managed DHCPv6 subnet"
}
```

## Schema

### Required

- `interface` (String) Interface this subnet is served on (must be enabled in the DHCPv6 general settings).
- `subnet` (String) Subnet in CIDR notation (e.g. `2001:db8::/64`).

### Optional

- `allocator` (String) Lease allocator strategy (empty = default, `iterative`, or `random`).
- `description` (String) Description of the subnet.
- `dns_servers` (Set of String) IPv6 DNS servers offered to clients.
- `domain_search` (Set of String) Domain-search suffixes offered to clients.
- `pd_allocator` (String) Prefix-delegation allocator strategy (empty = default, `iterative`, `random`, or `flq`).
- `pools` (String) Address pools for the subnet (newline-separated ranges).

### Read-Only

- `id` (String) UUID of the subnet.

## Import
