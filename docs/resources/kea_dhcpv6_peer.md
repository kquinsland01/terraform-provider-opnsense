# opnsense_kea_dhcpv6_peer (Resource)

Manages a typed DHCPv6 HA peer using the snake-case API available in OPNsense 26.7.7 or newer. Keeping Kea DHCPv4, DHCPv6, and HA services disabled is supported while staging configuration. The deprecated generic `opnsense_kea_peer` alias is intentionally not exposed.

## Example Usage

```terraform
resource "opnsense_kea_dhcpv6_peer" "standby" {
  name = "standby.example.test"
  role = "standby"
  url  = "http://[2001:db8:31::2]:8000/"
}
```
