# opnsense_unbound_dnsbl (Resource)

This singleton preserves the established HCL and import ID while translating it to the current `dnsbl.blocklist` wire shape. On an empty appliance it creates and privately tracks its own item. If any item already exists, normal create stops with an import-required diagnostic instead of overwriting unowned configuration. Import may explicitly adopt exactly one existing item and rejects multiple candidates. Once tracked, unrelated items are preserved. `safe_search` is stored by current OPNsense releases in `general.safesearch`, but remains owned here for state compatibility.

Destroy is state-only and does not reset or delete the appliance blocklist.

Stable OPNsense 26.7.7 and newer use the current array-backed item contract described above. Older stable releases retain the established singleton DNSBL contract and permissive legacy reconfigure response. The provider verifies the appliance identity and version before selecting either path.

## Example Usage

```terraform
resource "opnsense_unbound_dnsbl" "blocklist" {
  enabled     = true
  safe_search = true
  type        = ["ag"]
  blocklists  = ["telemetry.example"]
  nxdomain    = true
}
```
