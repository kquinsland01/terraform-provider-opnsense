# opnsense_kea_dhcpv6_pd_pool (Resource)

Manages a typed DHCPv6 delegated-prefix pool using the snake-case API available in OPNsense 26.7.7 or newer. `prefix` accepts either an aligned IPv6 address or CIDR whose length matches `prefix_len`. Delete pools before their parent subnet. The deprecated generic `opnsense_kea_subnet` alias is intentionally not exposed.

## Example Usage

```terraform
resource "opnsense_kea_dhcpv6_pd_pool" "clients" {
  subnet_id     = opnsense_kea_dhcpv6_subnet.lan.id
  prefix        = "2001:db8:31::"
  prefix_len    = 48
  delegated_len = 64
  description   = "Client delegations"
}
```
