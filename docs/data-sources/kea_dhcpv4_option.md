# opnsense_kea_dhcpv4_option (Data Source)

Reads an exact option UUID on **stable OPNsense 26.7.7+** with the compatible
eight-field model. Requires read access to `/api/core/firmware/status` and
`/api/kea/dhcpv4/get_option`; use the appliance API permission selector.
No mutation or service activation is performed. All eight fields are returned
strictly, using selected keys rather than labels. Missing/null/malformed fields,
invalid flags and unavailable endpoints are errors, not fabricated empty values.
Data and description remain literal strings. `force` is only the stored flag,
not a packet-level guarantee. This view does not attach options or recover ordered
parent linkage. Older cores, OpenTofu and packet delivery are unverified.

## Example Usage

```terraform
data "opnsense_kea_dhcpv4_option" "domain" {
  id = "00000000-0000-0000-0000-000000000001"
}
```
